## Цель:

## Aдресное пространство

**10.Dn.Sn.X**

## Назначение октетов

### Dn — DC1 = 0-10

| DN | Назначение |
|------|-----------|
| 0 | Loopback Underlay|
| 1 | Loopback Overlay |
| 2 | P2P |
| 3 | Reserved |
| 4–7 | Services / VRF |
| 8–9 | Management |

---
### HOST — идентификатор узла

| Диапазон | Роль |
|--------|------|
| 1–99 | Spine |
| 101–199 | Leaf |
| 200–220 | Border / Gateway |
