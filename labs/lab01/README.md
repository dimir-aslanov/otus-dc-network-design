# Aдресное пространство

## Общий формат

`10.<Dn>.<Host>.<X>`

---

## Назначение октетов

### Dn — номер DC и тип сети  
Для **DC1 используется диапазон `0–10`**

| Dn | Назначение |
|----|------------|
| 0 | Loopback Underlay |
| 1 | Loopback Overlay |
| 2 | P2P |
| 3 | Reserved |
| 4–7 | Services / VRF |
| 8–9 | Management |

---

### Host — идентификатор узла

| Диапазон | Роль |
|---------|------|
| 1–99 | Spine |
| 101–199 | Leaf |
| 200–220 | Border / Gateway |

---

## Правила адресации

- Loopback интерфейсы — `/32`
- P2P линковка — `/31`
- Spine — только underlay
- Leaf — underlay + overlay (VTEP)
