# Домашнее задание
----------------

Проектирование адресного пространства

## Цель:

Собрать схему CLOS;  
Распределить адресное пространство.


## Aдресное пространство

10.<POD>.<BLOCK>.<HOST>
---

## Назначение октетов

### POD — локация / DC

| POD | Описание |
|----|----------|
| 10 | DC1 / LAB |
| 20 | DC2 |
| 30 | DR / Future |

---

### BLOCK — тип сети

| BLOCK | Назначение |
|------|-----------|
| 0 | Loopback Underlay|
| 1 | Loopback Overlay |
| 2 | P2P |
| 3 | Reserved |
| 4–7 | Services / VRF |
| 8–9 | Management |

---

### HOST — идентификатор узла

| Диапазон | Роль |
|--------|------|
| 1–99 | Spine |
| 101–199 | Leaf |
| 200–220 | Border / Gateway |
